# 📊 تحلیل داده‌های فروش Superstore با Python

## 📌 معرفی پروژه
در این پروژه، دیتاست Superstore با استفاده از زبان برنامه‌نویسی Python مورد تحلیل قرار گرفته است.  
هدف اصلی پروژه، انجام یک فرآیند کامل تحلیل داده شامل پاک‌سازی داده‌ها (Data Cleaning)، تحلیل اکتشافی داده‌ها (EDA) و مصورسازی داده‌ها (Data Visualization) است.  
این تحلیل کمک می‌کند الگوهای فروش، سودآوری، رفتار مشتریان و عملکرد مناطق مختلف شناسایی شوند.

# 📦 بررسی داده‌های پرت (Outlier Analysis)

### Sales  
وجود مقادیر بالا طبیعی است و حذف خودکار انجام نشد.

### Quantity  
با روش IQR مقادیر غیرمنطقی شناسایی و مدیریت شدند.

### Discount  
مقادیر بالا ممکن است Outlier باشند اما لزوماً اشتباه نیستند.

### Profit  
مقادیر منفی به‌عنوان سفارش‌های زیان‌ده واقعی حفظ شدند.

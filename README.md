# 💡 مهم‌ترین نتایج پروژه

برخی از مهم‌ترین نکات و Insightهای به‌دست‌آمده عبارت‌اند از:

- فروش و سود دارای یک رابطهٔ مثبت کلی هستند.
- تخفیف‌های بالا می‌توانند سودآوری را کاهش دهند.
- برخی محصولات فروش بالایی دارند، اما لزوماً سودآوری بالایی ندارند.
- عملکرد فروش و سود در Categoryها و Sub-Categoryهای مختلف متفاوت است.
- مناطق مختلف از نظر تعداد سفارش، فروش، سود و تخفیف رفتار متفاوتی دارند.
- گروه‌های مختلف مشتریان دارای الگوهای متفاوتی در داده‌ها هستند.
- روش‌های مختلف ارسال دارای توزیع سفارش متفاوتی هستند.
- هر Outlier لزوماً یک دادهٔ اشتباه نیست و باید با توجه به ماهیت کسب‌وکار بررسی شود.
